# Mizyyy

Electron-плеер с функциями:

- поиск музыки в интернете (через iTunes Search API),
- онлайн-воспроизведение найденных треков (preview URL),
- встроенный список результатов и управление проигрыванием.

## Запуск

```bash
npm install
npm start
```

## Линт/проверка синтаксиса

```bash
npm run lint
```
