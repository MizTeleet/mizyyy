# LeetMusic (папка-приложение)

Всё приложение собрано в одной папке **LeetMusic**.

## Как запускать
- На Linux/macOS: откройте папку `LeetMusic` и запустите файл `LeetMusic`.
- На Windows: откройте папку `LeetMusic` и запустите `LeetMusic.bat`.

После запуска плеер автоматически откроется в браузере.

## Куда кидать музыку
Складывайте треки в папку:

- `LeetMusic/Music/`

Примеры:
- `LeetMusic/Music/track1.mp3`
- `LeetMusic/Music/track2.flac`

Поддерживаемые форматы: `mp3`, `wav`, `ogg`, `m4a`, `flac`.
